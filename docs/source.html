Repository

The repository is github.com/SCcagg5/procurauth. It is neutral: it names no product.

procurauth/
spec/the protocol
bindings/mcp/the MCP binding
schemas/JSON schemas
conformance/the cases, as data
crates/the Rust workspace: five tools and the PEP library
docs/documents and the changelog
site/the source of this site
IMPLEMENTATIONS.mdthe known implementations
LICENSEApache-2.0, for the code
LICENSE-docsCC BY 4.0, for the texts

IMPLEMENTATIONS.md lists the known implementations. The README of each crate and the docs/ directory describe the tools and the library.

Releases

Release v1.0 gives the five tools as programs, built from the source of the tag. Each archive holds the five programs. A file SHA256SUMS lists the SHA-256 sum of each archive, and each archive has its own .sha256 file.

PlatformArchiveSHA-256
Linux, x86-64procurauth-tools-1.0-x86_64-linux.tar.gz.sha256
Linux, ARM64procurauth-tools-1.0-aarch64-linux.tar.gz.sha256
macOS, Apple siliconprocurauth-tools-1.0-aarch64-macos.tar.gz.sha256
macOS, Intelprocurauth-tools-1.0-x86_64-macos.tar.gz.sha256
Windows, x86-64procurauth-tools-1.0-x86_64-windows.zip.sha256

SHA256SUMS lists all the sums. Each program shows its licence with --version.

Check a download

Linux x86-64
$ REPO=https://github.com/SCcagg5/procurauth$ BASE=$REPO/releases/download/v1.0$ curl -LO $BASE/SHA256SUMS$ curl -LO $BASE/procurauth-tools-1.0-x86_64-linux.tar.gz$ sha256sum --check --ignore-missing SHA256SUMSprocurauth-tools-1.0-x86_64-linux.tar.gz: OK$ tar -xzf procurauth-tools-1.0-x86_64-linux.tar.gz$ ./access-lint --version

Build from source

Build
$ git clone https://github.com/SCcagg5/procurauth$ cd procurauth$ git checkout v1.0$ cargo build --release

Contribute

  1. Open an issue in the issue tracker to report an error or to propose a change. Cite the number of the paragraph.
  2. For a change of the text, keep the numbers of the paragraphs. A paragraph that leaves the text keeps its number with the word "Unused".
  3. For a change of a rule, add or change a conformance case that cites the paragraph.
  4. Open a pull request. A contribution is under the licence of the files that it changes.

Write the documents in ASD-STE100 Simplified Technical English, as the specification does.

Changelog

1.0

The first release.

  • The protocol and the MCP binding.
  • The JSON schemas and the conformance data, series U, D and E.
  • The tools access-lint, fake-pdp, access-token, keycheck and access-conformance.
  • The reference PEP library in Rust.
  • Binaries for Linux, macOS and Windows, with SHA-256 sums.

ProcurAuth

ProcurAuth lets a backend manage the rights of its users and the rights of the AI agents that act for them. Version 1.0.
